# Задание: обнаружение мошеннических вакансий

Курс: 4IZ582 / 4IZ583. Требования: https://4iz565.gitlab.io/project/
Датасет: https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction
Локальный файл: `data/fake_job_postings.csv`.
Target: `fraudulent` — 1 для мошеннической вакансии, 0 для реальной.
AI-компонент: Route B — сравнить текстовые embeddings с TF-IDF baseline.

## Что требуется для сдачи

- EDA: структура, типы, пропуски, баланс классов и минимум два содержательных графика.
- Preprocessing: минимум две операции pandas; отсутствие утечки данных.
- Модели: минимум два семейства алгоритмов, отдельный test и стратифицированная CV на train, подбор параметров.
- Оценка: accuracy, ROC AUC или Average Precision, ROC-кривая и confusion matrix с обоснованием порога. Test — только для финальной оценки.
- Route B: школьный endpoint, ключи в переменных окружения, кеш embeddings в CSV, число запросов и время получения.
- Сдача: ZIP с notebook, HTML-экспортом, данными и AI-кешем. Относительные пути; полный офлайн-запуск до 30 минут. Объяснить решения, вклад участников и использование AI.
